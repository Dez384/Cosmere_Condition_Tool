# Cosmere Useful Macros
This module is a prototype for adding custom conditions to the Cosmere RPG game system. To use this module:
1. Open `world.js` and edit the `NewCon` object. The keys are the name of the condition and the values are the filepath for the icon.
2. If you want the conditions to appear on the character sheet, set `isCondition` to `TRUE`. Set it to `False` if you only want the conditions on the token.
3. Load Foundry and activate the module. Individual conditions can be disabled in the settings menu.
